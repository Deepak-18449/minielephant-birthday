# Digital Gift Website

Open `index.html` in a modern browser.

Included:
- Animated gift box
- 4-digit PIN gate
- Photo-memory section
- Mini choice game
- Typewriter letter
- Birthday cake and candle interaction
- Birthday name reveal
- Thank-you message sent through WhatsApp
- Full-page background video at `assets/Bg_video.mp4`
- Your uploaded song at `assets/song.mpeg`

Demo PIN: 0204

To customize:
1. Edit the letter text in `script.js`.
2. Replace `assets/IMG_1.jpg.jpeg` through `assets/IMG_4.jpg.jpeg` to change the four memory photos.
3. Change `const PIN="0204"` in `script.js` to your preferred 4-digit PIN.
4. Edit the page styles in `style.css`.
5. Change `BIRTHDAY_NAME` in `script.js` to the birthday person's name.
6. Replace `WHATSAPP_NUMBER` in `script.js` with the recipient's international phone number, without `+`, spaces, or dashes.
7. Keep `assets/song.mpeg` in the same relative location so the song plays.
